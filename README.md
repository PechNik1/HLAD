# Хлад (Khlad) — статическая версия

Мобильное PWA для учёта продуктов и сроков годности. **Без сервера, без базы данных, без сборки** —
чистый HTML/CSS/JS. Работает на любом статическом хостинге (GitHub Pages, Netlify, Cloudflare Pages, VPS + nginx),
офлайн после первой загрузки (Service Worker), устанавливается на домашний экран как приложение.

Данные хранятся в `localStorage` устройства. Общий доступ — через ссылку-приглашение или файл JSON.

---

## 1. Бесплатный хостинг 24/7 на GitHub Pages (5 минут)

1. Создайте репозиторий на GitHub, например `khlad` (публичный).
2. Загрузите **содержимое этой папки** в корень репозитория
   (через веб-интерфейс: «uploading an existing file» или `git push`).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder `/root` → Save**.
4. Через 1–2 минуты приложение доступно по адресу:
   `https://<ваш-логин>.github.io/khlad/`

GitHub Pages — это CDN: сайт работает 24/7, бесплатно, с HTTPS из коробки.
Обновления: просто `git push` — Pages пересоберёт сайт автоматически.

Опционально: подключите свой домен (**Settings → Pages → Custom domain**), например `khlad.ru`.

### Установка на телефон как приложение
- **Android/Chrome**: откройте сайт → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone/Safari**: «Поделиться» → «На экран “Домой”».

## 2. Что уже заложено для подписок (монетизации)

- **Экран «Подписка и тарифы»** (вкладка «Ещё»): бейдж тарифа, сравнение возможностей, цены (Месяц 149 ₽ / Год 990 ₽).
- **Лимит бесплатной версии**: `FREE_LIMIT = 30` продуктов в `index.html` — при превышении
  показывается оффер апгрейда.
- **Флаг `pro`** в данных: открывает безлимит.
- **Промо-коды** (`PROMO_CODES` в `index.html`) — ручная выдача доступа тем, кто оплатил
  (Boosty / Patreon / переводом). Мастер-ключ по умолчанию: `KHLD-PRO-FOREVER` — смените его.
  Это рабочая схема уже сейчас, без сервера.

> ⚠️ Проверка кода происходит в браузере, поэтому ключ виден любому, кто откроет код страницы
> или репозиторий. Промо-код — удобство, а не защита: любой может вручную выставить себе
> `pro: true` в localStorage. Настоящая защита — только с серверной проверкой (этап 2 дорожной карты).

### Дорожная карта платежей
1. **Сейчас (без сервера)**: продавать доступ вручную и выдавать промо-коды.
2. **Серверная часть (бесплатный тир)**: Cloudflare Workers / Vercel Functions + KV/D1
   для проверки кодов и платежных webhook'ов. Фронт остаётся на GitHub Pages — всё ещё $0/мес.
3. **Платёжные провайдеры** (зависит от юрисдикции): CryptoBot API, ЮKassa, Prodamus,
   для зарубежной аудитории — Stripe/Paddle (Paddle проще с НДС).
4. **Платные фичи под подписку**: фоновые push-уведомления и онлайн-синхронизация
   (нужен сервер — реалистично через Supabase/Firebase free tier),
   отчёты и история изменений.

## 3. APK для Android

Из этой статической версии APK собирается проще всего через **Capacitor**:

```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init Khlad com.yourname.khlad --web-dir=.
npx cap add android
npx cap open android   # открывает Android Studio → Run ▶ или Build > Generate Signed Bundle/APK
```

Скопируйте файлы этого проекта в web-корень перед `npx cap add android`.
Альтернатива — **TWA (Bubblewrap)**, если хотите публикацию в Google Play поверх GitHub Pages URL.

## 5. Ограничения статической версии

- Нет общей базы между устройствами (обмен только ссылкой/файлом) — решается платной синхронизацией.
- Push-уведомления приходят, только пока открыто приложение (фоновые push требуют сервера).
- Очистка данных браузера / смена устройства = потеря списка, если не делать экспорт.
